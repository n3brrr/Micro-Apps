# Micro-Apps

## FilmFinder

This is a simple movie finder that allows users to find movies based on their genre.

## Instructions

1. Get an API key from The Movie Database (TMDb)
2. Replace `<Your API Key>` in `script.js` with your API key
3. Open `index.html` in your browser
4. Select a genre and click "Play" to see a random movie

## Notes

- The API key is not included in the code for security reasons
