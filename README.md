# Mini Micro Apps

This repository contains a collection of mini micro apps—small, independent projects and exercises created to practice web development skills.

Each app is focused on a specific concept or feature, such as working with APIs, JavaScript, or other web technologies.

## Structure

- Each subfolder contains a separate mini micro app or exercise.
- Files include source code, resources, and instructions if needed.

## Purpose

To experiment, learn, and reinforce programming concepts by building small, hands-on projects.

Feel free to explore and try out each mini micro app!
