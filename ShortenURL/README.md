# Micro-Apps

## ShortenURL

This is a simple URL shortener that allows users to shorten long URLs to make them easier to share and remember.

## Instructions

1. Get an API key from Bitly
2. Replace `<Your API Key>` in `script.js` with your API key
3. Open `index.html` in your browser
4. Enter a long URL
5. Click "Shorten" to generate a shortened URL
6. Copy the shortened URL and share it

## Notes

- The API key is not included in the code for security reasons
